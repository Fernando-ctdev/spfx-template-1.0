# 🚀 SPFx Template

> Um boilerplate moderno, opinativo e pronto para produção para desenvolvimento de soluções SharePoint Framework (SPFx).

Este template não é apenas um ponto de partida; é uma **plataforma de aceleração** que traz as melhores práticas de engenharia de software para o mundo SPFx.

## ✨ Destaques

*   **⚡ Arquitetura SPA Real**: Navegação instantânea sem recarregar a página.
*   **🎨 Design System Híbrido**: O poder do **Tailwind CSS** com a conformidade do **Fluent UI**.
*   **🤖 CLI Integrada**: Gerador de código (`pnpm run generate`) para criar páginas, componentes e serviços em segundos.
*   **🛡️ Enterprise Ready**: Estrutura escalável, Tipagem forte e Configuração centralizada.

## 🛠️ Stack Tecnológica

*   **Core**: SharePoint Framework (SPFx) 1.21
*   **Frontend**: React 17 + TypeScript
*   **Roteamento**: React Router DOM v6
*   **Estilos**: Tailwind CSS 3 + Fluent UI v8
*   **Estado & Dados**: TanStack Query (React Query) + PnPjs v4
*   **Ícones**: Lucide React
